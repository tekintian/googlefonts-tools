# 项目架构（四层分层架构）

```
googlefonts-download-tools/
├── main.go                          # 应用入口（CLI + Server 双模式）
├── config.ini                       # 配置文件
├── go.mod                           # 依赖管理（Go 1.22）
├── Makefile                         # 构建脚本
├── app/
│   ├── model/
│   │   └── task.go                  # 数据模型（Task, TaskProgress, TaskStatus）
│   ├── repository/
│   │   ├── repo.go                  # TaskRepository 接口定义
│   │   ├── repo_sqlite.go           # SQLite 实现 + 共享扫描函数 + NewRepo 工厂
│   │   ├── repo_mysql.go            # MySQL 实现
│   │   └── repo_postgres.go         # PostgreSQL 实现
│   ├── service/
│   │   ├── download_engine.go       # 字体下载引擎（并发下载+ZIP打包）
│   │   ├── task_manager.go          # 异步任务管理器（Worker池+SSE发布订阅）
│   │   └── notify_dispatcher.go     # 多通道通知（钉钉/微信/邮件/Webhook）
│   └── controller/
│       ├── base_ctr.go              # 基础控制器+中间件（CORS/Logging）
│       ├── router.go                # HTTP路由配置
│       ├── task_ctr.go              # 任务API接口（CRUD + SSE进度）
│       ├── page_ctr.go              # 页面控制器（首页/签名页/下载/进度）
│       └── templates.go             # HTML模板（首页/进度/结果/错误/404）
└── utils/
    ├── db/db.go                     # 数据库连接管理（SQLite/MySQL/PostgreSQL）
    ├── http_utils.go                # HTTP请求工具
    ├── security_utils.go            # MD5签名工具
    ├── file_utils.go                # 文件/目录工具
    ├── ini_utils.go                 # INI配置文件解析
    └── tools_utils.go               # 通用工具函数
```

## 核心功能实现

| 功能 | 状态 | 说明 |
|------|------|------|
| **CLI 下载模式** | ✅ | `-mode download` 命令行直接下载，支持单URL和批量文件 |
| **Web Server 模式** | ✅ | `-mode server` 启动HTTP服务，提供Web界面和API |
| **异步任务调度** | ✅ | Goroutine Worker池 + Channel，可配置Worker数量 |
| **幂等性设计** | ✅ | 基于MD5(URL)生成唯一签名，避免重复下载 |
| **永久链接** | ✅ | `/d/{sign}` 查看状态，`/d/{sign}/download` 下载ZIP |
| **SSE 实时进度** | ✅ | Server-Sent Events推送下载进度，30s心跳保活 |
| **多数据库支持** | ✅ | SQLite(默认)/MySQL/PostgreSQL，Repository模式抽象 |
| **多通道通知** | ✅ | 钉钉/微信/邮件/Webhook，配置化启用 |
| **并发下载** | ✅ | 带信号量的Goroutine池，可配置并发数 |
| **重试机制** | ✅ | 指数退避重试，可配置重试次数 |
| **下载计数** | ✅ | 记录ZIP文件下载次数 |
| **缓存复用** | ✅ | 已成功的任务直接返回结果，无需重新下载 |

## 构建和运行

由于终端 PATH 环境变量过长导致无法在此处执行命令，请手动执行：

```bash
# 1. 安装依赖
go mod tidy

# 2. 构建
go build -o googlefonts-tools .

# 3. 运行 Web 服务模式
./googlefonts-tools -mode server -port 8000

# 4. 运行 CLI 下载模式
./googlefonts-tools -mode download -url "https://fonts.googleapis.com/css?family=Roboto:wght@400;700"

# 5. 批量下载
./googlefonts-tools -mode download -file urls.txt -output ./my-fonts
```

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/tasks` | 创建下载任务 |
| GET | `/api/v1/tasks/{sign}` | 查询任务状态 |
| GET | `/api/v1/tasks` | 列出所有任务 |
| GET | `/api/v1/tasks/{sign}/progress` | SSE实时进度 |
| GET | `/d/{sign}` | 永久链接-任务状态页 |
| GET | `/d/{sign}/download` | 永久链接-下载ZIP |
| GET | `/d/{sign}/progress` | 永久链接-SSE进度 |
